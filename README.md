# Community Fridge Finder

Community Fridge Finder is a one-page website made with HTML, CSS, and JavaScript.

## Made by

- Ridwan Zoha
- Aryanna Santana
- Jacob Lin

## Project purpose

The purpose of the website is to help people:

- Find nearby community fridges
- See the current condition of each fridge
- Log donations, pickups, cleaning, or problems
- Read recent community updates

## How to open the project

1. Open the folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension, or open the file directly in a browser.

## Main features

- One-page layout
- Search bar
- Fridge location cards
- Simple illustrated map
- Community update form
- Recent activity section
- About section
- Mobile-friendly design
- Browser localStorage

## Important note

The website uses localStorage, which means submitted updates are saved only in the current browser. A real version would use a database.

## GitHub Pages

Upload `index.html`, `README.md`, the `css` folder, and the `js` folder directly to your GitHub repository.

Then go to:

Settings → Pages → Deploy from a branch → main → /(root)
